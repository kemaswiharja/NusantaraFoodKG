# NusantaraFoodKG
This is the resource page, for our paper titled "Safe nusantara: a semi-automatic framework for engineering and populating a nusantara food ontology"

The paper can be downloaded in this url: 
**https://socjs.telkomuniversity.ac.id/ojs/index.php/ijoict/article/download/1042/452**

We also provide an ontology (NFOFor2026Book.owl) in this github page as a companion for our upcoming book in Indonesian Language, titled "Representasi Pengetahuan"
